## 1. AIにCAD設計を任せたら、自由なPythonより制約付きDSLの方が成功した

0xliclogさんの記事。FreeCADを操作するAIエージェントに、あらかじめ定義した操作をJSONで呼ばせるDSL方式と、Pythonコードを書かせるコード生成方式を比べている。前回の記事では、箱や円柱、穴あけといった単純な8タスクを各方式40回、計80回試し、コード生成の方が約26%少ないトークンで済んだ。ループや関数で操作をまとめられるためだ。ただし、それは少ない修正で終わる単純な課題だったからだ。今回は課題を難しくして比べ直し、タイトルのとおりDSL方式の方が成功したという。自由度が高いほど有利とは限らず、AIに与える手段をどこまで絞るかが成否を分けるという実例である。

出典: https://zenn.dev/0xliclog/articles/093e202c66fdd3

## 2. AIにどこまで行動させてよいのか?― AIの判断とAuthorizationを分離してみる

kondonatorさんの記事。前回は、履歴書のようなAIに読ませる文書の中に指示が紛れ込むと、AIがそれを実行してしまうかもしれないことを実験した。今回はその続きで、AIが文章を作るだけでなく、システムに対して「この処理を実行してください」と要求できる場合を考える。採用システムの例で、AIが出した要求をそのまま通すのではなく、AIの判断と、その操作を許可するかどうかの認可(Authorization)を切り分ける設計を試している。AIが誤った判断や、紛れ込んだ指示に従った判断をしても、許可の側で止められる構造にしておく、という考え方だ。エージェントに実際の操作権限を渡す前に、一度整理しておきたい論点である。

出典: https://zenn.dev/kondonator/articles/88ed39d4950a0f

## 3. 「うん」と言うたびに黙る音声AIが、GPT-Liveに替えたら劇的にリアルになった

toriken さんの記事。1on1の練習アプリで、相談者役を務める音声AIの基盤を、OpenAIのRealtime APIから、9月10日にAPIで一般提供となったGPT-Liveに切り替えた記録である。Realtime APIでは、ユーザーが相づちを打つたびにAIの話が止まる問題が直せなかった。GPT-Liveでは出なくなり、そのために書いていた回避処理も不要になった。一方で、ターン検出の設定や発話の開始・終了を知らせるイベントがなくなったため、その部分は自分たちで作り直したという。新しいモデルに替えて何が良くなり、何を自前で補う必要が出たのか、両面が書かれた移行記録として読める。

出典: https://zenn.dev/toriken/articles/gpt-live-migration-from-realtime-api

## 4. オートパイロットは外せる人間を前提にしている — AI時代のエンジニア技能維持を航空業界に学ぶ

shimitaroさんの記事。AIにコードを書かせる時代に、エンジニアは何の技能を残しておくべきかを、航空業界の制度から考えている。FAA、EASA、ICAOという三つの機関が何を言っているかを区別して整理した結果、答えは「自分で書く力」よりも「自動化から引き継ぐ力」に寄っていったという。パイロットは普段ずっと手で操縦しているわけではない。それでも、自動操縦が外れたときに立て直せる状態を、規制当局が訓練の仕組みとして維持させている。そこからソフトウェアエンジニア向けの訓練の考え方を引き出している。日本の制度は扱っていない旨も断られている。AIに任せる割合が増えるほど、任せられなくなった瞬間の備えが問われる、という視点が参考になる。

出典: https://zenn.dev/shimitaro/articles/eb45d8d63c7bd1

## 5. MySQL の View を使った疑似 Row Level Security に対して思いつく限りの攻撃をしてみる

shora_kujira16さんの記事。マルチテナントのアプリで、テナントごとのデータをtenant_idカラムで分ける場合、PostgreSQLには行レベルのアクセス制御であるRLSが標準で用意されている。MySQLにはネイティブなRLSがない。アプリ側で毎回WHERE句にtenant_idを付ける方法は、付け忘れが怖い。そこで、Viewを使って疑似的にRLSを実現する構成を作り、思いつく限りの攻撃を試して、どこまで耐えられるかを確かめている。設計を作って終わりにせず、破る側に回って検証する姿勢がよい。MySQLでテナント分離を考えている人は、実際の攻撃結果に目を通す価値がある。

出典: https://zenn.dev/shora_kujira16/articles/cd2496df09be36
