## 1. exit 1でClaude Codeフックは止まるか33回試した

Claude Codeが git push を打つ前に、PreToolUse フックで秘密の値の混入を検査している環境での報告。検査で何か見つかると終了コード1で終わる作りだったが、「止めた」という記録の10秒後に、同じ commit が実際にリモートへ届いていた。筆者はこの挙動を33回の試行で確かめている。フックの仕様では、終了コード1は警告扱いにとどまり、実行を止めるには別の返し方が要る、という方向の整理である。リポジトリは非公開だったので実害は小さかったが、公開リポジトリなら秘密が漏れていた。ガードを置いたことと、ガードが効いていることは別の話で、止める仕組みは止まる場面を実際に再現して確認する必要がある。

出典: https://zenn.dev/ai_jarvis/articles/88ffbd67ebdec1

## 2. 完了フラグで二重実行は止まるか、8プロセスで210回試した

同じ筆者による姉妹編。セッション開始のたびに SessionStart フックが無人処理を起こし、1日1回で足りる要約作業をする。終わったら日付入りの完了フラグを置き、次回はフラグがあれば何もしない設計だった。ところが朝にセッションを2つほぼ同時に開くと、両方がフラグのできる前に判定を通り、処理が2本走る。「確認してから作る」の間に隙間があるためで、典型的な競合状態である。筆者は8プロセスを同時に動かして210回試し、実際にどれだけ重複するかを測っている。フラグは逐次実行の前提でしか守ってくれない。排他が必要なら、確認と作成を一つの原子的な操作にまとめる。古くからある教訓を、エージェントのフックという新しい場所で踏み直した例だ。

出典: https://zenn.dev/ai_jarvis/articles/d5a86ce187b139

## 3. 8,000件超のテストでCIが60分タイムアウト。Mutationを削らず約19%高速化した話

AWSのIaCをレビュー・修正するOSSを開発している筆者のCIが、GitHub Actionsの60分上限に達して終了するようになった。テストは8,000件以上で、セキュリティや証跡の整合性を確かめるミューテーションテストも含む。テストを減らしたりSKIPしたりすれば時間は縮むが、このOSSはAIエージェントによる変更を安全に検証すること自体が機能なので、検証を弱める選択肢は取れない。そこで、テストの削除とSKIPをしないという方針を先に決め、その制約の中で約19%の短縮を得た。時間を縮めるときに、何を削ってはいけないかを先に宣言する。その順序が設計判断として参考になる。

出典: https://zenn.dev/nobu_13/articles/98264b7214adfd

## 4. 同じカーネルCVE、AL2023は即対処・Ubuntuは配布待ちだった話

Linuxカーネルの同じ脆弱性に、Amazon Linux 2023のサーバとUbuntu 22.04(AWSカーネル)のサーバが同時に引っかかった。AL2023側はその場で修正版を適用できたが、Ubuntu側は修正版がまだ配布されておらず、待つしかなかった。記事ではAL2023で実際に行った手順と確認方法を示したうえで、ディストリビューションごとにパッチの配布時期が違う点を扱っている。脆弱性対応の期限は、CVEの公開日ではなく、使っているディストリビューションが修正を出す日で決まる。待つ間にどう緩和するかまで含めて、運用手順に織り込んでおく必要がある。

出典: https://zenn.dev/daishiro/articles/kernel-cve-al2023-ubuntu-patch-timing

## 5. ACMのメール検証終了:期限の分解、ARN維持の資料差、ACME導入後に残る運用責任

AWS Certificate Managerのメール検証の終了を、日付ごとに分解した記事。2027年1月1日は新リージョンでの提供終了、2027年3月31日は全リージョンでの新規申請終了、2027年9月30日は既存証明書の更新終了、2028年3月15日はCA/Browser Forumの期限、と四つに分かれる。既存の証明書が9月30日に一斉に失効するわけではなく、更新できなくなる点が実務上の論点だと筆者は整理する。さらに、発表ブログは「ARNを維持したままメールからDNSへ移せる」と書くが、別の資料との間に食い違いがあり、その扱いを論じている。期限は一つではなく、更新の窓口が閉まる日から逆算する、という見方が実用的だ。

出典: https://zenn.dev/xim2jp_tokyo/articles/neta-37-zenn-summary
